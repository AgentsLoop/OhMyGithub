# Prompt rubric

Use this rubric when rewriting a sparse game request into an issue prompt.

- State the concrete playable outcome and the intended player experience.
- Include a small number of observable acceptance criteria: core loop,
  controls, feedback, win/lose or restart state, and visual cohesion.
- Keep the scope small enough for one issue-triggered implementation run.
- Prefer inspectable behavior over vague quality claims.
- Preserve the user's subject and intent without copying surrounding skill
  invocation text.

This is prompt guidance only. The issue-e2e skill remains kickoff-only and
does not run the full Gauntlet Loop.
