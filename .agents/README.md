# Worker Agents Skills

This repository bundles the baseline skills installed by [Worker
Agents](https://github.com/agents-dev/workerAgents).

The bundled skills are available under [`skills/`](skills/):

- `mcp-duckgo` — imported from `aahl/skills@mcp-duckgo`.
- `image-search` — imported from `z0gsh1u/oh-my-writing-skill@image-search`.
- `gauntlet-loop` — imported from `robonuggets/gauntlet-loop@gauntlet-loop`.
- `load-sketchfab-threejs` — local asset inspection, normalization, and Three.js/PlayCanvas A/B viewer skill.
- `opencode-zen-completions` — use the OpenCode Zen chat completions API for implementation work.

The original upstream licenses are preserved in
[`third-party-licenses/`](third-party-licenses/).
