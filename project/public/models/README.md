# Models
Procedural PBR weapon and arena are built in code (no external GLB required).

To use a Sketchfab GLB:
- Place file at `public/models/weapon.glb`
- The loader will auto-detect it (see src/main.js extension hook). Keep attribution in `public/models/ATTRIBUTION.md`.

Current build uses fully procedural M4A1 SOPMOD model for instant load and AAA PBR material fidelity.
