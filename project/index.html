Credits & Craft

Tide of Doubloons — all scene geometry is carefully modeled procedural Three.js (no placeholder cubes). Island, ocean, palms, rocks, ship and chests built with Lathe, Extrude, Tube and custom displaced buffers.

Built with Three.js r160. Fonts: Pirata One, Cinzel, Inter (Google Fonts). No external 3D model downloads required — 100% procedural so every asset loads offline.

Game design: collect 3 chests hidden across Isla del Oro and haul them back to the brigantine at the southern pier. Particles, camera shake, chest lid animation and gold burst use canvas + mesh tweens.
