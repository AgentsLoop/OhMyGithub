◆ NEXUS WARS — COMMAND BRIEFING

A StarCraft-inspired RTS. Gather Minerals and Vespene Gas, expand your Supply, build an army, and destroy the enemy Command Center. You start with 4 SCVs and a Command Center. The enemy AI is already harvesting.

◆ RESOURCES

  • Mineral Fields — blue crystals, 8 per patch, SCVs auto-gather
  • Vespene Gas — green geysers, build Refinery first
  • Supply — Supply Depot +8, blocked = can't train

◆ BUILDINGS

  • Command Center (400M) — trains SCV, +15 Supply
  • Supply Depot (100M) — +8 Supply
  • Barracks (150M) — trains Marine, Zealot, Tank
  • Refinery (75M) — on Vespene geyser, enables gas

◆ UNITS

  • SCV (50M) — worker, gathers & builds
  • Marine (50M) — ranged fighter
  • Zealot (100M) — melee bruiser, high HP
  • Siege Tank (150M+75G) — heavy, long range, splash

◆ CONTROLS

  • Drag box select   Shift+click add   Ctrl+A select all army
  • Right Click move/attack/gather   A attack-move
  • Build: select SCV → click build button or B S R D
  • P pause   Mouse Wheel zoom   Space jump to base
