Every Loop spawns an isolated worktree — a fresh checkout that must survive on its own. Enemies are merge conflicts rushing the core. If isolation breaks, the loop regresses.

HOW ISOLATION WORKS

• Arena = worktree at /tmp/opencode-worktree-<run>/project with sparse-checkout: project.
• Each Loop increments difficulty: +3 enemies, +8% speed, −1s spawn interval.
• Regression check: survive 22s or clear wave to advance. Core at 0% = loop failed → retry same loop.
• Visual proof: arena GLB centered & framed, robot/knight use matching GLTFLoader, ACES tonemap.
